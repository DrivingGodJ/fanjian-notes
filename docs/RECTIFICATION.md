# 书页展平与逐字定位

倾角校正、透视 / 弯曲展平、逐字定位是三个不同步骤。旋转一张照片不能展开弯曲纸张，展平照片也不等于每个字已准确定位。

## 使用

导入照片后，先裁掉背景与无关区域，点击“矫正透视与弯曲”。UVDoc 自动处理，照片和文字都在本机。检查预览，不满意可点“撤销照片矫正”；需要时再微调倾角，然后开始识别。展平会重采样照片，后续识别、旁注和导出统一基于这张处理后的照片。

点击旁注可看到对应原字的框及连接线。如果框不对，可选“点选照片中的原字定位”，放大后点击原字中心；也可修改整行原文。未可靠匹配的旁注在原文面板内待确认。旧记录会升级定位，保留手动点位、偏移、隐藏 / 删除、样式和视图；旧照片需要展平时，选择重新识别进入预处理。

OCR 和逐字核对使用相同的官方识别模型，无额外识别模型下载。可选 UVDoc 增加约 30.2 MiB，模型管理可预先缓存；未缓存且断网时，可继续普通识别。浏览器可能清理缓存。

## 查阅的开源方案

| 项目 | 功能与采用情况 |
| --- | --- |
| [jscanify](https://github.com/puffinsoft/jscanify) · MIT | 浏览器 OpenCV 的页面边缘及四角透视变换，适合平面纸张；不能仅靠四角处理纸张内部弯曲。本次未引入。 |
| [page_dewarp](https://github.com/mzucker/page_dewarp) · MIT | 根据文字行拟合三次纸张模型，依赖 Python / SciPy / OpenCV；不是可直接调用的浏览器组件。本次未移植。 |
| [UVDoc](https://github.com/tanguymagne/UVDoc) · MIT | 神经网格书页展平。本次采用 Paddle 提供的该模型 ONNX 版本，在已有 ONNX Runtime Web 1.24.3 WASM Worker 内运行。 |
| [Paddle 官方图像矫正文档](https://github.com/PaddlePaddle/PaddleOCR/blob/main/docs/version3.x/module_usage/text_image_unwarping.en.md) | 已核对实际 PaddleX 预处理 / 后处理与模型归档。模型来自官方静态下载地址，固定 SHA-256 校验；未假定浏览器 PaddleOCR.js 包暴露此 API。 |

UVDoc 许可保存在 [UVDoc-MIT.txt](../public/licenses/UVDoc-MIT.txt)。构建脚本准备归档与 ONNX 文件，不把模型大文件提交到 Git；浏览器只访问本站静态文件。展平与识别分阶段释放 Worker，限制同时驻留的模型内存。

## 逐字定位如何变化

官方 PaddleOCR.js 0.4.2 的行结果只有 `text / poly / score`，不能拿字符数量平均切分后声称得到真实字框。当前独立定位模块按官方输入规范重新读取同一识别模型，保留 CTC 时序信息，以字间像素留白细化边界，再与整行原文做序列核对。

重复字对应有歧义、漏字或字形不匹配时，不强行把后面的字挪到前一个位置。只有用户明确改过本行文字时，才允许唯一的替换关系；单独更改方向不表示用户确认了原文。框与分数仍是估算，CTC 时间点并非字符检测框，分数也不是统计校准概率。

生成样本的实测误差、离线推理和交互检查见 [测试报告](../TESTING.md)。真实 iPhone / Android、密集排版、反光、严重曲面、遮挡及整页精度仍需原始照片验证；自动展平可能产生不理想的重采样或裁切，必须检查预览。手动四角校正和字符级检测模型尚未实现。
